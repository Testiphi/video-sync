# FrameSync

FrameSync 用于对齐并比较两个带计时器的视频。它可以通过 OCR 或手动标注建立计时器数值与视频时间之间的映射，再将两个视频定位到同一计时器时刻。

项目是一个纯前端单页应用。视频只在浏览器本地处理，不会上传到服务器。

## 在线使用

访问 [GitHub Pages](https://testiphi.github.io/video-sync/) 即可使用。

受浏览器安全策略限制，通过 GitHub Pages 使用时不能直接读取本地文件路径，请通过“浏览”按钮或拖放方式加载视频。

## 本地运行

```bash
git clone https://github.com/Testiphi/video-sync.git
cd video-sync
python -m http.server 8765
```

然后访问 [http://localhost:8765](http://localhost:8765)。

## 使用方法

### 1. 加载视频

- 点击“浏览”选择视频文件，或将文件拖放到对应面板。
- 本地运行时也可以输入视频路径并点击“加载”。
- 所有视频处理均在本地浏览器中完成。

### 2. 选择计时器区域

- 在画面上拖出计时器所在区域。
- 可以使用滑块或随机跳转查看不同画面。
- “自动”按钮会使用右上角的默认区域。
- 选区使用百分比坐标保存，不依赖视频分辨率。

### 3. 校准计时器

可以使用 OCR 自动识别，也可以手动填写计时器数值。

#### OCR 识别

1. 框选完整计时器，尽量排除其他文字，四周保留少量边距。
2. 选择计时格式和小数位数。默认是 `MM:SS.mmm`；显示 `83.456` 这类总秒数时改选“总秒数”。
3. 点击“采样 5 帧”，在五个不同时间段各采一个点。
4. 点击“Tesseract OCR”。每个点会检查三个邻近画面，并根据需要尝试不同图像处理方式和文字分割方式。
5. 检查预览和“待确认”提示。可以手动修改数值，或核对候选后点击“确认”。

截图按原比例缩放，识别输入包括原图、灰度增强、二值化和反色版本。只有格式、小数位数、置信度、邻近帧走时规律和全局校准都通过检查的结果，才会自动写入校准值。自动校准需要至少三个一致的有效点；人工校准仍可使用两个点。

默认最低置信度为 80%，允许误差为 50 毫秒。普通速度视频的“视频秒 / 计时秒”保持为 1；计时器走 1 秒对应视频中的 2 秒时填 2。粗粒度计时器会根据其显示精度放宽误差阈值，页面会显示实际使用的阈值。暂停、重置、画面遮挡或不符合设定比率的区域会转为待确认。

浏览器支持视频帧回调时，校准使用回调提供的帧时间；已经停在目标位置或浏览器不支持该接口时使用 `currentTime`，这种路径无法保证帧时间精度。取帧超时不再继续识别旧画面，邻近帧被采用时也会同步更新校准时间和预览。

可选择“标准”或“精度优先”模型。后者使用 `tessdata_best` 英文浮点模型，下载量和耗时更大，不保证对所有计时器字体都更准确。首次使用需要联网下载引擎和语言数据，之后分别缓存两种模型；视频和截图不上传。

手动填写或确认至少一个采样点后，点击“对比两种模型”，即可让两种模型识别同一组标注截图。比较不会替换现有校准值。结果统计完整计时值正确率、错误接受率、数值对应的视频时间误差和识别耗时；模型加载耗时单独记录。“导出识别报告”保存本地 JSON，其中包括设置、识别候选、截图、时间来源和校准结果。

模型比较属于单帧识别评估，不能代替整个多帧校准流程的对齐误差测试。报告中的基准必须由人核对，自动识别结果未经确认不能作为真实标注。项目未附带真实视频测试集，也没有训练计时器专用模型。

#### 手动标注

1. 将视频停在计时器清晰可见的位置。
2. 输入当前画面的计时器数值并添加校准点。
3. 至少添加两个位于不同时间位置的校准点。

应用使用 Theil-Sen 回归计算 `视频时间 = a × 计时器 + b`，显示拟合优度和最大残差。超过允许误差、计时器不递增或计时值没有变化时，不能构建有效索引。只有两个点时无法检查离群值，建议补充更多点。

### 4. 同步对比

两个视频完成校准后会显示同步对比区域。

- 拖动滑块可以将两个视频定位到同一计时器时刻。
- 使用偏移按钮可以微调视频 B，支持 0.01 秒、0.1 秒和 1 秒步长。
- 点击“同步播放”可以从当前位置同时播放两个对齐后的视频，再次点击即可暂停。

## 实现方式

- HTML、CSS 和原生 JavaScript，主要代码位于 `index.html`。
- 使用 `<video>` 元素解码视频，并通过 Canvas 显示对比画面。
- 使用 [Tesseract.js](https://tesseract.projectnaptha.com/) 在浏览器中识别计时器。
- `ocr.js` 负责图像预处理、多帧和全局一致性校验、模型比较及报告导出。
- 使用 Theil-Sen 稳健线性回归建立计时器与视频时间的映射。
- 播放过程中按照校准结果调整播放速率，并在出现明显漂移时重新同步。

## 验证

无需安装测试依赖即可运行解析、取帧事件和识别校验的自动化测试：

```bash
node --test tests/ocr-parser.test.cjs tests/ocr-frame.test.cjs tests/ocr-quality.test.cjs
```

另有 `tests/browser-smoke.cjs`，需要可被 Node 加载的 Playwright 和已安装的 Chrome。运行 `node tests/browser-smoke.cjs` 会在浏览器中生成计时器视频，验证实际解码、预处理、OCR 和两种模型的加载。它需要联网下载 OCR 依赖，合成画面的通过结果不代表真实视频准确率。
